## About

**MediBridge** is an AI-powered healthcare triage assistant built using **Google Gemini**.

It understands user-reported symptoms, asks intelligent follow-up questions, and provides guidance toward an appropriate level of care.

The goal is simple:

> **Make initial healthcare guidance faster, simpler, and more accessible.**

## User Experience

MediBridge follows a **conversation-first healthcare UX**.

### Simple

Users can describe symptoms using everyday language without needing medical terminology.

### Conversational

Instead of presenting users with long and complicated forms, MediBridge gathers information through natural follow-up questions.

### Actionable

The objective is to help users understand their **next step**, rather than simply providing information.

### Safety-Focused

The system is designed to encourage professional medical attention when potentially serious symptoms are identified.
